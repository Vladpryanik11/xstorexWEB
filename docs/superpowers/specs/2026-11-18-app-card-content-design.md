# Карточка приложения по образцу lazyshop и DDE Store: блоки и демо-каталог

Дата: 2026-11-18. Согласовано с владельцем в треде «Заполнить карточки приложений по образцу lazyshop и ddestore».

## Зачем

Каталог в разработке и на скриншотах заполнен заглушками «Тестовое приложение N» без картинок. Владелец попросил заполнить карточки по образцу lazyshop.app и DDE Store (diyorde.com) вместе с картинками. Сравнение: `/mnt/project-files/reports/2026-11-18-app-cards-lazyshop-ddestore.md` (Project Files).

## Решения владельца

- Иконки и скриншоты приложений можно брать с сайтов конкурентов: это материалы из App Store. Логотип, оформление и тексты DIYORDE и lazyshop по-прежнему не берём.
- Импорт метаданных через iTunes API по-прежнему не делаем.
- Тексты описаний пишем сами по образцу структуры, дословно не копируем.
- Модов и «Plus/Premium»-версий в каталоге нет, только оригинальные приложения.

## Новые блоки страницы приложения

1. **Устройства.** Строка «Устройства: iPhone, iPad» в «Информации» и подпись под скриншотами. Источник — `UIDeviceFamily` из IPA (воркер уже его читает). Новое поле `AppVersion.deviceFamily Int[]` (по умолчанию `[1]`), заполняется при загрузке IPA. API: `AppDetail.devices: ('iphone' | 'ipad')[]` по последней опубликованной версии.
2. **Дата обновления.** «Обновлено 3 ноября 2026 г.» — дата последней опубликованной версии, строка в «Информации». Данные уже есть (`versions[0].publishedAt`).
3. **Пометка для удалённых из App Store.** Под бейджем «Удалено из App Store» одна спокойная фраза: «Его больше нет в App Store, но установить можно здесь». Без технических слов.
4. **Описание группами.** Админ пишет обычный текст. Строка, которая начинается с «• » или «- », — пункт списка; подряд идущие пункты — один список. Строка перед списком, которая кончается двоеточием, — подзаголовок группы. Остальное — абзацы. Свёрнутое описание по-прежнему показывает 3 строки и «ещё».
5. **Похожие приложения.** Внизу страницы рельс «Похожие приложения»: до 12 видимых приложений той же категории, кроме текущего, по убыванию рейтинга, затем по имени. Нет категории или похожих — блока нет. API: `AppDetail.similar: AppCard[]`.

## Демо-каталог

- `pnpm --filter @xstore/db seed:demo` (из корня `pnpm db:seed:demo`) заполняет локальную базу 23 настоящими приложениями: категории, иконки и 5 скриншотов в рамке iPhone, подзаголовки, описания группами, разработчик, рейтинг, языки, размер, совместимость, устройства, отметка «Удалено из App Store», подборки главной.
- Картинки лежат в `packages/db/demo/media/<slug>/` (webp: иконка 256×256, скриншоты 460 px по ширине).
- Скрипт запускается только на базе на `localhost`/`127.0.0.1` и перед заполнением удаляет только каталог (приложения, версии, категории, подборки); сотрудники и настройки остаются.
- IPA в демо нет: версии ссылаются на несуществующий ключ, установка из демо не работает. На прод карточки попадают только через админку вместе с IPA и «основанием для распространения».
- E2E-сид (`seed:e2e`) не меняется: тесты опираются на его данные.
