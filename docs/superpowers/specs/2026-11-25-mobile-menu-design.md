# Мобильное меню: одна белая панель (25.11)

Решения владельца 25.11 13:27–13:34 в треде «Переделать мобильное выпадающее меню». Макет: https://claude.ai/artifact/RCh89HGzep2VeAU5hvKDfd, спор дизайнеров: `reports/2026-11-25-spor-mobilnoe-menu.md` в папке проекта. Заменяет меню-карточки (React Bits Card Nav) из §5 `2026-11-17-premium-ui-design.md` для экранов уже 48em; шапка на ПК не меняется.

## Что было и что убрано

Было: белая панель, внутри три серые карточки с подписями «Каталог / Доступ / Помощь», девять строк с иконками. «Подключить iPhone» — обычная строка, на iPhone 13 панель не помещалась.

Убрано: подписи групп, серые карточки, «Главная», иконки у строк, отдельная строка «Поддержка».

## Как теперь (вариант А5 + А4, «Войти» — Л3)

Основа — мобильное меню Aceternity Resizable Navbar (https://ui.aceternity.com/components/resizable-navbar), перенесено на CSS Modules и токены.

Одна белая панель под круглой кнопкой меню, сверху вниз:

1. Слово «Xstorex» («X» `--x-text`, «storex» `--x-blue`, шрифт заголовков) — ссылка на главную.
2. Синяя карточка подписки (градиент от `--x-cta`), подпись мелкими заглавными, заголовок, белая кнопка и под ней кнопка-стекло (полупрозрачная белая):
   - гость: «Подписка» / «Весь каталог в одной подписке» / «Подключить iPhone» → `/get` / «Есть доступ? Войти» → `/signin`;
   - вошёл без подписки: то же, вторая кнопка «Мой доступ» → `/access`;
   - с подпиской: «Подписка активна» / «Весь каталог уже ваш» / «Мой доступ» → `/access`, второй кнопки нет.
3. Каталог крупно (Inter Tight 600), с тонкими линиями: «Удалённые из App Store», «Premium доступы», «Поиск».
4. Вторичное меню мелко и серым (`--x-text-2`): «Как это работает» (`/#how`), «Вопросы», «Тарифы» (у подписчика без «Тарифов»).
5. Строка «Поддержка: support@xstorex.app» (ссылка mailto).

Текущая страница — синим (`--x-cta`) и `aria-current="page"`. Поведение окна не меняется: фокус внутри, Escape, закрытие при переходе и при ширине от 48em, анимация раскрытия, `prefers-reduced-motion`.
