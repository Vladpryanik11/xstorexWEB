# Премиальный интерфейс Xstore — спецификация

Дата: 2026-11-17. Статус: решения согласованы владельцем (vlad) в треде «Подобрать премиальный дизайн интерфейса». Заменяет разделы 6.1 и 6.2 спецификации `2026-11-02-xstore-design.md`.

## 1. Цель

Сделать интерфейс цельным и «дорогим», без вида стандартного AI-шаблона. Основа: белый, голубой и синий, максимально обтекаемые формы и одна яркая анимация. Остальные движения тихие и отвечают на действия пользователя.

Структура страниц, тексты, сценарии и правила установки не меняются. Меняются токены, шапка, герой главной и отдельные компоненты.

Макет палитры (вариант E): https://claude.ai/artifact/A3x4saaLnN6TSkz78NwSxx

## 2. Что меняется по отношению к diyorde

- Шапка больше не синяя полоса с градиентом. Эталон `assets/header-logged-in.png` и правило «шапка совпадает с эталоном» отменяются.
- Синий герой на главной заменяется светлым «ледяным».
- От diyorde остаются структура страниц и компонентов: рельсы, ряды 3×N, ряд иконок, чипы, обложки 16:10, карточка приложения, плавающая плашка установки, футер.
- Файлы DIYORDE в продукт по-прежнему не попадают.

## 3. Палитра (токены)

| Токен | Значение | Роль |
|---|---|---|
| `--x-white` | `#FFFFFF` | панели, карточки, шапка-пилюля, поле поиска |
| `--x-ice` | `#F2F8FD` | фон страницы |
| `--x-sky-50` | `#E3EDFD` | фон героя, тихие кнопки, активный пункт меню |
| `--x-sky-200` | `#A8CFF4` | ободки, конец луча, мягкие подложки |
| `--x-sky-400` | `#4DA3FF` | свечение, градиенты иконок; не для текста |
| `--x-blue` | `#1A6EEA` | кнопки, переключатели, активный чип, ссылки-действия |
| `--x-blue-deep` | `#0A4BBF` | нажатие и наведение на синие кнопки |
| `--x-text` | `#0E1A33` | основной текст, уведомления |
| `--x-text-2` | `#5F6B85` | второстепенный текст |
| `--x-quiet-fg` | `#0F5FD6` | текст тихой кнопки на `--x-sky-50` |
| `--x-ok` / `--x-ok-bg` | `#0F7743` / `#E3F5EA` | успех |
| `--x-warn` / `--x-warn-bg` | `#A35A00` / `#FDF0DC` | внимание |
| `--x-err` / `--x-err-bg` | `#C62F35` / `#FDE6E7` | ошибка |
| `--x-shadow` | `0 12px 32px -20px rgba(26,110,234,.45)` | тень панелей |
| `--x-shadow-sm` | `0 4px 12px -4px rgba(26,110,234,.14)` | тень чипов и пилюль |

Контраст текста к своему фону не ниже 4.5:1 (WCAG AA). Проверено для всех пар текст/фон из таблицы. Небесный и голубой на текст не идут.

Старые токены (`--x-ink`, `--x-page`, `--x-surface`, `--x-header-gradient`, `--x-glass`) удаляются после переноса всех мест, где они используются. Админка получает те же токены.

Тёмная тема в этот этап не входит.

## 4. Формы

- Панели и крупные карточки: радиус 1.75rem (28px).
- Карточки поменьше, обложки, скриншоты: 1.5rem.
- Кнопки, поля ввода, поиск, чипы, бейджи, шапка, уведомления: полная пилюля (`999px`).
- Иконки приложений: iOS-сквиркл, радиус 22.5%.
- Тени только голубые (`--x-shadow`, `--x-shadow-sm`), серых теней нет.
- Разделители — волосяная линия `rgba(26,110,234,.10)`.

## 5. Шапка

Основа: [Floating Glassmorphic Navbar](https://21st.dev/@themeocean/components/floating-glassmorphic-navbar-with-morphing-pill-indicator) + поведение [Resizable Navbar](https://ui.aceternity.com/components/resizable-navbar) + стекло [Glass Surface](https://reactbits.dev/components/glass-surface). Мобильное меню: [Card Nav](https://reactbits.dev/components/card-nav).

- Белая стеклянная пилюля плавает над страницей: отступ сверху `.75rem + safe-area`, по бокам `--x-gutter`. От 48em пилюля компактная: шириной по своим ссылкам и по центру, не на всю страницу (решение владельца от 2026-11-19); на телефоне — на всю ширину за вычетом полей. Фон `rgba(255,255,255,.78)`, `backdrop-filter: blur(12px) saturate(1.4)`, тень `--x-shadow`, внутренний белый ободок 1px.
- Состав (по спецификации v2, §2): «Каталог», «Блог», «Вопросы», «Поддержка» | справа гость видит «Тарифы» + «Войти», подписчик — «Мой доступ», вошедший без доступа — «Тарифы» + «Мой доступ». «Выйти» живёт на странице «Мой доступ». Шапка узнаёт сессию в браузере после загрузки (`GET /access`), поэтому страницы одинаковы для всех.
- Логотипа-значка в шапке нет (решение владельца от 2026-11-19). Первым в пилюле стоит слово «Xstorex» текстом (Manrope 700, шрифт заголовка h2, «X» цветом `--x-text`, «storex» — `--x-blue`) — ссылка на главную с подписью «Xstorex, на главную» (решение владельца от 2026-11-20, образец [Aceternity Resizable Navbar](https://ui.aceternity.com/components/resizable-navbar)). На ПК после слова — тонкий разделитель и меню; на телефоне слово слева, «Тарифы» и кнопка меню справа. Знак Xstore (`apps/web/public/brand/mark.png`, квадрат во весь кадр, сайт скругляет 22.5%) остаётся в подвале, он же иконка вкладки (`app/icon.png`) и иконка экрана «Домой» iPhone (`app/apple-icon.png`, без прозрачности).
- Активный пункт (`aria-current="page"`) — подложка `--x-sky-50`, текст `--x-quiet-fg`. Подложка перетекает между пунктами при наведении и переходе (shared layout). Без hover-указателя подложка стоит на активном пункте.
- «Тарифы» (и «Мой доступ» у подписчика) — синяя пилюля; «Войти» — тихая ссылка цвета `--x-text-2`.
- При прокрутке больше 24px пилюля становится ниже (высота с 56px до 48px, ширина не больше 56rem) и усиливает размытие. Переход .32s `--x-ease`.
- Меньше 48em: в пилюле «Тарифы» (гость) и круглая кнопка меню. Кнопка раскрывает шапку вниз в ряд карточек (Card Nav): карточки «Каталог», «Доступ», «Помощь» со ссылками внутри. Карточка «Каталог» начинается со строки «Главная»; у каждой строки линейный значок 24px (у разделов — те же, что на плитках главной), строки выровнены по одной линии. Esc и тап вне закрывают, фокус удерживается внутри, тело страницы не прокручивается.
- Переключателя языка нет.
- Меню «Каталог» от 48em (вариант 3, решение владельца от 2026-11-20; образец [Aceternity Navbar Menu](https://ui.aceternity.com/components/navbar-menu)). «Каталог» — кнопка с `aria-expanded`; панель открывается при наведении (указатель мыши) и по нажатию или Enter, закрывается при уходе курсора с шапки и панели (с задержкой ~150 мс), по Esc (фокус возвращается на кнопку) и по клику вне. Панель — белая карточка `--x-radius-panel` под пилюлей, по центру, тень голубая; страница под ней слегка затемнена льдом и размыта. Слева два столбца пунктов: «Удалённые из App Store», «Premium доступы», «Популярные» (у каждого три иконки приложений раздела внахлёст, до загрузки и в пустом разделе — линейный значок раздела), «Весь каталог» и «Поиск» (линейные значки). Справа синяя карточка: гость и вошедший без доступа — «Весь каталог на месяц по одной цене» и кнопка «Смотреть тарифы» (`/pricing`); подписчик — «Подписка активна» и кнопка «Мой доступ» (`/access`). Иконки разделов браузер загружает один раз при первом наведении на шапку (`GET /catalog/sections/:slug`, первые три приложения). «Каталог» активен на `/catalog`, страницах разделов и `/search`. Без анимации при `prefers-reduced-motion`. На телефоне остаётся Card Nav.

## 6. Герой главной

- Фон `--x-sky-50` плавно переходит в `--x-ice`.
- За заголовком крупное белое слово XSTORE (декоративное, `aria-hidden`), как во Flinex.
- Заголовок цвета `--x-text`, под ним подзаголовок (`--x-type-body`, `--x-text-2`) и белая пилюля поиска с тенью `--x-shadow`.
- В конце главной, перед подвалом, блок «Как это работает»: заголовок секции и три белые карточки-панели (номер шага в голубом круге, заголовок `--x-type-h3`, строка текста `--x-text-2`); на iPhone карточки идут столбиком, от 48em — в ряд. Под карточками строка доверия `--x-type-ui`, `--x-text-2`.
- Под шапкой нет синей полосы и тонировки 6px.

## 7. Компоненты и анимации

| Где | Компонент | Источник |
|---|---|---|
| Тап по строке приложения → иконка перетекает в карточку-превью с «Установить» | Morphing Dialog | https://motion-primitives.com/docs/morphing-dialog |
| Края горизонтальных рельсов уходят в размытие | Progressive Blur | https://magicui.design/docs/components/progressive-blur |
| Подложка под активным чипом категорий и пунктом меню | Animated Background | https://motion-primitives.com/docs/animated-background |
| Стекло шапки | Glass Surface | https://reactbits.dev/components/glass-surface |
| Рамка iPhone вокруг скриншотов на карточке приложения | iPhone | https://magicui.design/docs/components/iphone |
| Прогресс установки по этапам | Staged Progress Bar | https://21st.dev/@dhxwhy/components/staged-progress-bar |
| Пошаговое подключение iPhone по UDID | Stepper (вертикальный) | https://21st.dev/@originui/components/stepper/vertical-with-inline-titles-and-descriptions |
| Луч по рамке рекомендуемого тарифа (только там) | Border Beam | https://magicui.design/docs/components/border-beam |
| Уведомления на сайте и в админке | Sonner | https://21st.dev/@shadcn/components/sonner |
| Флаги в редакторе приложения | iOS-переключатель (MIT) | https://uiverse.io/zanina-yassine/afraid-eel-50 |

Правила переноса:

- Исходники компонентов на Tailwind и `motion`. Код переносим в `packages/ui` или `apps/web/src`, классы Tailwind переводим в CSS Modules на токенах Xstore. Tailwind не добавляем.
- Новая зависимость: `motion` (одна, для shared layout и пружин). Sonner подключаем пакетом `sonner`. Для чисто CSS-эффектов (луч, мерцание, переключатель, прогрессивное размытие) библиотеки не нужны.
- Лицензии исходников сохраняем в комментарии над перенесённым компонентом.
- Каждый интерактивный элемент получает видимый `:focus-visible` и работает с клавиатуры.
- При `prefers-reduced-motion: reduce` перетекания заменяются мгновенной сменой, луч и мерцание стоят.
- Яркий момент один: Morphing Dialog. Анимаций появления секций при прокрутке нет.
