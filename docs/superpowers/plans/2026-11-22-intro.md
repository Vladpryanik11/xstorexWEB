# План: интро на главной

Спецификация: `docs/superpowers/specs/2026-11-22-intro-design.md`.

1. Тест и функция `introDecision` (`src/intro/decision.ts`): показ по адресу, метке, reduced motion, webdriver. Её же текст встраивается скриптом до отрисовки.
2. Модуль стилей `src/intro/intro.module.css` — перенос стилей исходника на CSS Modules; исключение в `typography.test.ts`.
3. Движок `src/intro/engine.ts` — перенос сценария, звука и холста из исходника на TypeScript; запуск и полная остановка.
4. Компонент `src/intro/Intro.tsx` и шрифты `src/intro/fonts.ts`; подключение в `app/(home)/layout.tsx`, обёртка страницы для проявления.
5. E2E `e2e/intro.spec.ts`; полный набор проверок; запись видео для владельца.
