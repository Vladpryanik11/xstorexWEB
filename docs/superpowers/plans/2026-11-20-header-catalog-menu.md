# План: меню «Каталог» в шапке на ПК (вариант 3)

Спецификация: `2026-11-17-premium-ui-design.md` §5, пункт «Меню „Каталог“» (решение владельца от 2026-11-20). Макет: `/mnt/project-files/screenshots/2026-11-20-header-variants/C-3-menyu-katalog.png`. Основа — ветка PR #25 (шапка без логотипа, компактная по центру).

## Задача 1. Данные меню (`apps/web/src/shell/nav.ts`)
- Тест: `catalogMenu(state)` возвращает пункты «Удалённые из App Store», «Premium доступы», «Популярные» (со slug раздела), «Весь каталог», «Поиск» и карточку подписки: гость/без доступа → `/pricing`, подписчик → `/access`.
- Тест: `isCatalogPath` истинен для `/catalog`, `/removed`, `/premium`, `/popular`, `/search` и их подстраниц, ложен для `/faq`.
- Реализация.

## Задача 2. Компонент `CatalogMenu` (`apps/web/src/shell/CatalogMenu.tsx`)
- Тесты (Testing Library): кнопка «Каталог» с `aria-expanded=false`; клик открывает панель с пунктами и ссылками; Esc закрывает и возвращает фокус; наведение открывает, уход курсора закрывает после задержки; на странице раздела кнопка помечена активной; иконки разделов приходят из `browserApi().section` один раз, ошибка оставляет линейные значки; подписчик видит «Мой доступ».
- Реализация: CSS Modules на токенах, `motion` только для подложки (как в NavLinks), появление панели — CSS-анимация, отключается при reduced motion.

## Задача 3. Встраивание в `Header`
- Тест: от 48em в ряду меню первая кнопка «Каталог», затем «Блог», «Вопросы», «Поддержка»; мобильное меню не меняется.
- Реализация, стили панели и затемнения.
