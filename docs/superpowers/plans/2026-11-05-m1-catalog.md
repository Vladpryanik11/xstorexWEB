# M1 Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browsable public catalog (home, app, category, list, search pages) fed by an admin who signs in with password + TOTP, uploads IPAs straight to MinIO, lets the worker inspect them (`ipa.inspect`), edits metadata imported from iTunes and publishes apps.

**Architecture:**
- API gets real modules: `auth` (staff part only), `audit`, `storage`, `catalog`, `admin-catalog`, `jobs`. Infra providers (config, Prisma, Redis, S3, queues) move into a global `InfraModule`.
- The worker gets DB and S3 access and two new queues: `ipa` (inspect) and `catalog` (iTunes import). Pure IPA parsing lives in a new Node-only package `@xstore/ios`.
- Web renders catalog pages with SSR through a typed client from `@xstore/shared`; admin pages live under `/admin` on the same tokens.

**Tech Stack:** M0 stack (exact versions in M0 plan) plus: `@aws-sdk/client-s3` and `@aws-sdk/s3-request-presigner` 3.x, `yauzl` 3.x + `yazl` 3.x (tests), `plist` 3.x, `bplist-parser` 0.3.x, `pngjs` 7.x, `sharp` 0.34.x (worker), `@node-rs/argon2` 2.x, `otpauth` 9.x. Pin the exact latest patch of each at install time and record it in `package.json` without `^`.

**Spec:** `docs/superpowers/specs/2026-11-02-xstore-design.md` — §3.1 (`auth` staff part, `catalog`, `storage`, `admin`), §4.4, §5 (Каталог, `User`, `Session`, `AuditLog`, `Setting`), §6.1, §6.3 (public pages and admin «приложения», «подборки и категории»), §6.4 (SSR, slugs, `SoftwareApplication`), §7, §8, §9, §11 → M1. Design values: `.claude/skills/xstore-design/SKILL.md`.

## Owner decisions this plan depends on

Approved by the owner on 2026-11-05 and already recorded in the spec (§5, §11, §14):
1. **Staff sign-in moves from M2 to M1.** The catalog admin and the upload endpoints cannot ship without authentication. M2 keeps UDID and email sign-in for users.
2. **New model `IpaUpload`.** It tracks multipart uploads and inspect results for admin uploads (M1) and Signer uploads (M6). Spec §5 has no such entity.
3. **New `App` fields:** `rating`, `ratingCount` (imported from iTunes; «Самый рейтинговый» needs them), `languages` (facts strip «Язык»), `itunesId`, `bannerKey` (hero carousel image), `hiddenReason` (hiding after a complaint).

## Global Constraints

- Everything in M0 Global Constraints still holds: exact versions, ESM, package names, ports, Russian-only copy, `{ code, message }` errors, LF, quoted paths, secrets only in `.env`.
- New package: `@xstore/ios` (Node-only; never imported by `apps/web` or `packages/ui`).
- API prefix `/api/v1`; admin endpoints under `/api/v1/admin/*`; every admin endpoint requires role `admin` (read-only `GET` on `/admin/jobs` also allows `support`).
- Every admin mutation writes one `AuditLog` row.
- IPA size limit for admin uploads: 10 GiB (`10 * 1024 ** 3` bytes). Multipart part size: 64 MiB. Presigned URLs live 15 minutes.
- Buckets (from `S3_BUCKET_PREFIX`, default `xstore-`): `<prefix>originals` (private), `<prefix>media` (anonymous read), `<prefix>signed` and `<prefix>uploads` (private; created now, used in M4/M6).
- Only `status = published` apps and `published` versions are visible outside `/admin`.
- Job defaults: `attempts: 5`, `backoff: { type: 'exponential', delay: 10_000 }`, `removeOnComplete: 1000`, `removeOnFail: false`.
- Do not copy DIYORDE images or texts. Category icons are drawn for Xstore.

## Review Focus

1. **Interrupted upload** (Wi-Fi drop, tab reload, same file chosen again): the upload resumes from the parts already in MinIO instead of restarting → Task 10 test `resumes from listed parts`.
2. **Hostile archive** (`../` paths, absolute paths, zip bomb, no `Info.plist`, two `.app` bundles): rejected with a Russian reason, nothing written outside the temp dir → Task 4 tests `rejects traversal`, `rejects bombs`, `rejects ambiguous payload`.
3. **Same version uploaded twice** (same bundle id, version and build): no duplicate `AppVersion`; the upload is rejected as `DUPLICATE_VERSION` «Эта версия уже загружена» → Task 5 test `duplicate version is rejected`.
4. **Hidden or draft app** reached by slug, search or a collection: 404 and absent from every list → Task 6 int test `hidden apps never leak`.
5. **Cyrillic names and slug clashes** («Яндекс Карты» twice): readable Latin slug, second gets `-2` → Task 3 tests `transliterates`, `uniqueSlug appends a counter`.

Rules: no absolute paths, no `..` segments, no backslashes; ≤ 200 000 entries; total uncompressed ≤ 32 GiB; any entry over 1 MiB with ratio `uncompressed / compressed > 200` is a bomb; exactly one `Payload/<name>.app/` directory with `Info.plist`.
  - `type IpaRejectCode = 'IPA_NOT_ZIP' | 'IPA_UNSAFE_PATH' | 'IPA_ZIP_BOMB' | 'IPA_NO_APP' | 'IPA_MANY_APPS' | 'IPA_BAD_PLIST' | 'IPA_NO_BINARY'`; each has a Russian text in `@xstore/shared` `errorMessages` (e.g. `IPA_ZIP_BOMB` «Архив подозрительно сильно сжат и отклонён»).
  - `readInfo(plist): IpaInfo = { name, bundleId, version, build, minIos?, deviceFamily: number[], executable, iconNames: string[] }` — `name` from `CFBundleDisplayName ?? CFBundleName`; icons from `CFBundleIcons.CFBundlePrimaryIcon.CFBundleIconFiles` (+ `~ipad` variant) and `CFBundleIconFiles`.
  - `readEncryption(macho: Buffer): { encrypted: boolean; arches: string[] }` — handles fat (`0xCAFEBABE`, big-endian, 32-bit offsets) and thin 64/32-bit (`0xFEEDFACF`/`0xFEEDFACE`); walks load commands for `LC_ENCRYPTION_INFO` (`0x21`) and `LC_ENCRYPTION_INFO_64` (`0x2C`); `cryptid` is the `uint32` at command offset 16. Encrypted if any slice has `cryptid !== 0`.
  - `cgbiToPng(buf: Buffer): Buffer` — returns the input when there is no `CgBI` chunk. Otherwise: drop the `CgBI` chunk; concatenate `IDAT` data and inflate it as raw deflate (`zlib.inflateRawSync`); undo the PNG row filters; swap BGRA→RGBA and un-premultiply (`c = a ? min(255, round(c * 255 / a)) : 0`); encode a standard PNG with `pngjs`.
  - `inspectIpa(path: string, tmpDir: string): Promise<InspectResult>` where `InspectResult = { ok: true; info: IpaInfo; encrypted: boolean; sizeBytes: number; sha256: string; iconPng: Buffer | null } | { ok: false; reason: IpaRejectCode }`. Reads the archive with `yauzl` (central directory only, random access), never extracts to disk except the icon and the main executable, which it streams.
- Produces (`@xstore/shared` queues): `QueueName.ipa = 'ipa'`, `QueueName.catalog = 'catalog'`; `ipaInspectJob = z.object({ uploadId: z.string() })`, `catalogImportJob = z.object({ appId: z.string() })`; `defaultJobOptions` (values in Global Constraints).
- Produces (worker): `WorkerDeps = { db: PrismaClient; s3: WorkerS3; queues: Record<QueueNameValue, Queue>; logger: Logger; config: WorkerConfig }`; `createIpaWorker(deps): Worker` handling `inspect`.
